# LLMs – Large Language Model Projects

A hands-on collection of projects focused on **Large Language Models (LLMs), Generative AI, Prompt Engineering, Conversational AI, and NLP**.

This repository documents my journey of learning and implementing LLM-based applications, starting from basic chatbots and progressing towards advanced AI-powered systems.

## 🚀 Projects

| # | Project | Description |
|---|---|---|
| 01 | Basic LLM Chatbot | Build a basic chatbot using a Large Language Model. |
| 02 | Context-Aware Chatbot | Develop a chatbot that understands and maintains conversational context. |
| 03 | Conversation Memory Chatbot | Implement conversation history and memory management. |
| 04 | Chatbot with Custom System Prompts | Control LLM behavior using custom system instructions. |
| 05 | Multi-Prompt Template Engine | Create reusable and dynamic prompt templates. |
| 06 | Text Summarization Application | Generate concise summaries from lengthy text. |
| 07 | AI Email Writer | Generate professional emails using LLMs. |
| 08 | AI Resume Analyzer | Analyze resumes and extract relevant information. |
| 09 | AI Interview Preparation Assistant | Generate interview questions and assist with preparation. |
| 10 | AI Text Classification System | Classify text into predefined categories using LLMs. |
| 11 | AI Translation Assistant | Translate text between different languages. |
| 12 | AI Question Answering System | Build a system that answers questions using natural language. |
| 13 | Structured JSON Output Generator | Generate structured JSON responses using LLMs. |
| 14 | LLM-Based Text Extraction | Extract meaningful information from unstructured text. |
| 15 | LLM API Integration Framework | Integrate LLM capabilities into applications through APIs. |
